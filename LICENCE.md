## 🧩 About

**Soulmask overlay** is a curated list of Soulmask open-source tools:

- **Overlays** — on-screen helpers, layout notes, resource viewer, status panel
- **Quality-of-Life Helpers** — inventory notes, crafting planner, HUD tweaks
- **Research Notes** — single-player layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Single-Player Helpers
- Status Panel — view health, stamina, and stats on screen
- Resource Viewer — track nearby materials in single-player
- Crafting Planner — organize recipes and materials
- Playback Notes — record and review base builds for study

### 🗺️ Map & HUD
- Map Overlay — readable map layer for single-player exploration
- HUD Tweaks — adjust on-screen element visibility
- Loot Notes — catalog loot tables and locations

### 🏋️ Base & Tribe Notes
- Base Planner — segment study of base layouts
- Tribe Notes — organize follower and thrall data
- Config Presets — save and switch helper profiles
